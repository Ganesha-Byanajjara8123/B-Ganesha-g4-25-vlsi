# 📖 Overview

The **EX/MEM Pipeline Register** is the third pipeline register in a **5-Stage RV32I Processor**.

After an instruction completes execution in the ALU, all generated results—including ALU output, memory write information, destination register details, and control signals—must be preserved before entering the Memory stage.

This register synchronizes those signals, ensuring that memory operations and write-back information remain stable during the next pipeline cycle.

---

# 🎯 Why is this Register Required?

The Execute stage produces all information required for memory access.

Without the EX/MEM Register, these values would continuously change as the next instruction enters the Execute stage.

This register isolates the Execute and Memory stages, allowing both stages to operate simultaneously without corrupting intermediate results.

# 🔄 Pipeline Position

```
Execute Stage
      │
      ▼
┌──────────────────┐
│ EX/MEM Register  │
└──────────────────┘
      │
      ▼
 Memory Stage
```

# ✨ Features

- ✅ Transfers ALU computation results
- ✅ Stores memory write data
- ✅ Stores memory write mask
- ✅ Stores destination register number
- ✅ Stores write-back source selection
- ✅ Stores load control information
- ✅ Stores PC + 4 and Immediate Data
- ✅ Supports asynchronous reset
- ✅ Fully synchronous pipeline operation

---

# 📌 Signals Stored

### Datapath Signals

- ALU Result
- PC + 4
- Immediate Data
- Branch / Target Address
- Memory Write Data
- Destination Register (rd)

### Memory Control Signals

- Data Memory Write Enable
- Data Memory Write Mask
- Load Size
- Load Unsigned

### Write-Back Control

- Register Write Enable
- Result Source Selection

---

# ⚙️ Working Principle

At every rising clock edge, the register captures all outputs generated by the Execute stage.

```
Execute Stage

↓

ALU Result
Store Data
Immediate
PC+4
Control Signals

↓

EX/MEM Register

↓

Memory Stage
```

These registered outputs are then used by:

- Data Memory
- Load Unit
- Write-Back Logic

to complete memory access and prepare data for the final write-back stage.
