# 📖 Overview

The **MEM/WB Pipeline Register** is the final pipeline register in the processor.

Its responsibility is to preserve the outputs generated during the Memory stage and safely deliver them to the Write-Back stage, where the selected result is finally written into the Register File.

This register carries every possible write-back source, allowing the Write-Back multiplexer to choose the correct value for the destination register.

---

# 🎯 Why is this Register Required?

The Write-Back stage cannot directly use signals generated by the Memory stage because new instructions are already entering the pipeline.

The MEM/WB Register isolates both stages by storing all write-back information until the next clock cycle.

This guarantees correct register updates without interference from subsequent instructions.

---

# ⚙️ Working Principle

At every positive clock edge, the register captures all outputs generated by the Memory stage.

```
Memory Stage

↓

ALU Result
Loaded Data
PC+4
Immediate
Added Data

↓

MEM/WB Register

↓

Write Back Stage
```

The Write-Back multiplexer then selects the appropriate source and updates the destination register.
